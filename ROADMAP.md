# Roadmap

This roadmap describes the planned direction of the repository. It is a living document: phases may be reordered or adjusted as I learn what matters most. Status is updated honestly as work is completed.

## Phases

| Phase | Focus | Outcome | Status |
|---|---|---|---|
| 0 | Environment, Git, GitHub, repository scaffolding, first CI | Public repository with a green build | In progress |
| 1 | Swift fundamentals | Swift package with tests | Planned |
| 2 | Advanced Swift: protocols, generics, memory management, concurrency | Swift package with tests and ADRs | Planned |
| 3 | Data structures and algorithms (in parallel with other phases) | Tested implementations and benchmarks | Planned |
| 4 | SwiftUI and Project 01: Swift Playground Lab | First macOS application | Planned |
| 5 | Architecture and persistence, Project 02: Developer Dashboard | MVVM application with tests | Planned |
| 6 | AppKit and system integration, Project 03: System Monitor | Application using public system APIs | Planned |
| 7 | UI testing, performance and accessibility, Project 04: Productivity Studio | Fully tested local-first application | Planned |
| 8 | Project 05: Signature application, releases and public profile | Polished flagship application | Planned |

## Quality bar

A project is considered ready to present only when it:

- builds without warnings and passes its tests,
- has a README with screenshots and an ARCHITECTURE document,
- has been checked for accessibility and in light and dark appearance,
- passes continuous integration,
- documents its major decisions as Architecture Decision Records.

## Principles

- Quality over quantity.
- Honest progress: no inflated statistics and no artificial commits.
- Every claim in this repository is backed by code, tests or documentation.
