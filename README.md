# Apple Engineering Journey

A public, honest record of my path from Swift fundamentals to professional macOS application development.

> **Status:** early stage. The repository scaffolding is in progress and no projects have been published yet.

## Goals

- Learn Swift, SwiftUI and AppKit through working, tested code.
- Build macOS applications with documented architecture decisions.
- Practice a professional engineering workflow: Git, pull requests, CI, testing and documentation.

## Environment

- macOS 27 on Apple Silicon (M1 Max)
- Xcode 27.1, Swift 6.4

## Planned content

- Swift fundamentals and advanced Swift (Swift Package Manager modules with tests)
- Data structures and algorithms
- SwiftUI, AppKit and macOS system integration
- Software architecture and engineering documentation
- Five macOS applications, from a Swift learning lab to a signature app

The detailed plan will live in `ROADMAP.md`.

## How this repository is built

I work with an AI assistant acting as a mentor and code reviewer. Every module is built, run and tested on my own machine, and my learning notes are kept in the project documentation. Nothing here is presented as more than it is.
